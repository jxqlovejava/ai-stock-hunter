# rodya-caijing-studio — 财经研究输出契约与可证伪研究方法论

> 源码：https://github.com/nekopunch11/rodya-caijing-studio
> 定位：把"分析一下"这句随意提示词，落成有来源、可证伪、可交付的专业财经研究报告——覆盖 A 股 + 港股的 7 大研究场景，产出 DOCX 报告 / 客户合规卡片+文案 / PPT 三种形态。自称"财经内容台"（不是荐股器），明令反对用模糊的"AI 综合评分"代替真实分析。

与白泽现有 `guardrails` 的数据溯源、质量加权、时效性校验、输出契约**高度互补**：白泽重"决策管道评分"，该项目重"研究产出的可审计性与合规边界"。可作为 diagnose/attribute 输出阶段的方法论模板。

## 一、架构与路由（父 SKILL → 7 子模块）

```
SKILL.md（父：路由 + 通用工作流）
  ├── references/           共享层：数据/方法/合规/视觉（15 个文件，一处改动全局生效）
  ├── tests/                研究安全、响应契约、视觉契约测试
  ├── caijing-fundamental/  这家公司好不好？（论点驱动的深度研究）
  ├── caijing-earnings/     这季报实不实？（consensus vs guidance vs 季节性）
  ├── caijing-valuation/    现在贵不贵？（PB-ROE / 反向 DCF / 分位定位）
  ├── caijing-risk/         有没有雷？（M-Score / Z-Score / A股红旗库）
  ├── caijing-industry/     产业链怎么排？（行业结构）
  ├── caijing-ipo-a/        A 股打新破发风险（Wilson 置信区间）
  └── caijing-ipo-hk/       港股打新（保荐人/基石/绿鞋）
```

**父 SKILL 路由规则**：

| 规则 | 行为 |
|------|------|
| 稳定命令直通 | `/caijing:fundamental` 等 7 个命令绕过路由直达对应模块 |
| 按提示词路由 | "全面分析这家公司"→fundamental（内部含简版估值/风险）；"能不能买/该不该买"→valuation 只答"贵不贵"；混合问题→每模块各产一份内核 |
| 接力规则 | fundamental 只做简版估值/风险；更深需求接力到 valuation/risk 模块做增量分析，"不重复劳动" |
| 交付形态 | 只有用户点名要汇报/PPT/deck 时才合成合并 PPT；默认 DOCX |

## 二、方法内核（估值 / 排雷的数值方法论）

### caijing-valuation — "现在贵不贵"

只输出 **价格 vs 价值坐标，不是买卖信号**。九个分析块：

| # | 分析块 | 核心内容 |
|---|--------|---------|
| 1 | 估值锚适配 | 周期股→PB/EV-EBITDA（"低 PE 常是周期高点"）；银行保险→PB-ROE/内含价值；高增长→PS/PEG；稳定消费→PE/股息率；地产→NAV/PB |
| 2 | 纵向历史分位 | 5/10 年分带；当前值/分位%/距中位数距离（B 级数据） |
| 3 | **分位有效性检查（价值陷阱防护）** | "分位便宜≠便宜"：增长换挡（近3年 vs 前5年 CAGR）/行业渗透见顶/商业模式变迁/利率 regime 变化，任一命中→"历史分带参考价值降级" |
| 4 | 横向同业分位 | 3-8 家同业 P75/中位/P25，估值必配 ROE/增速（PB-ROE 散点或 PEG 逻辑）；异常低价须过"便宜的合理性"检查；A/H 对比须标注会计口径/币种/流动性 |
| 5 | **反向 DCF 隐含预期（杀手锏）** | 由市值反推隐含长期增速 vs 过去 5 年实际；必须报告终值占 EV 比重（占比高→结论强度降、敏感度变宽）；负 FCF/金融/地产 NAV/未商业化豁免；**无目标价** |
| 6 | 补充坐标 | A/H 溢价、股东回报（股息+回购）、SOTP（集团股：分部指标/净债/控股折价/双重计算检查） |
| 7 | 环境坐标 | 10 年国债、市场 ERP 分位、港股美元流动性；铁律：只给坐标，不做"利率会降"预测 |
| 8 | 三情景敏感性 | 乐观/中性/悲观只列关键假设变量；**禁止输出目标价/买卖区间/动作建议** |
| 9 | 交叉验证 | ≥2 个独立方法（历史/同业、反向 DCF、SOTP/NAV、股东回报），冲突时说明哪个假设最敏感——不做机械平均 |

**内核字段**：固定 8 个关键数字 + 研究方法字段（同业池与筛选理由、三情景变量与触发、口径基准、摊薄股本、终值占比、交叉验证、**≥2 条证伪条件**）。

### caijing-risk — "有没有雷"

| 机制 | 内容 |
|------|------|
| 学术模型（结果标"估算"） | Beneish M-Score（美国样本，仅作中国市场的预警参考不作裁决）；Altman Z-Score（制造/非制造两个版本 + 模型适用性与误报控制表） |
| A 股红旗库（每雷必带公告证据） | 大存大贷；非标审计意见（含强调事项段）；异常其他应收款（资金占用）；在建工程长期不转固（利润平滑）；审计师/CFO 频繁变更；高比例股权质押；违规担保与重大诉讼；商誉/净资产比；存货/应收异常增长；减持与解禁时间表；监管记录 |
| 港股红旗库 | "老千股"行为（频繁合股/摊薄配股）、CCASS 持仓集中度、审计师规模/更换史、长期停牌 |
| 跨市场恶化因子 | 增速放缓、盈利质量侵蚀、营运资本异常、现金流持续低于净利润、估值-基本面背离、内部人信号——每条须回链公告而非仅价格下跌/传闻 |

**四类雷**：财务雷 / 治理雷 / 经营雷 / 交易结构雷。

**裁决规则**：
- **一票否决**（直红不加权）：审计非标及更差、立案调查、未解决的违规担保、老千股史；
- 否则按严重度加权 → 红/黄/绿三档；
- **无证据不报雷**；证据不足进"待核实线索"队列；合理解释与反面证据降级且防重复计数。

**措辞红线**：禁止 造假/骗子/必爆/庞氏 等词；M/Z 结果必须表述为"进入统计预警区间"而非"公司操纵利润"。

## 四、研究安全与输出契约（核心借鉴面）

### 1. 最高不变量
> **任何 gate、合规、时效或数据降级，只能降低结论置信度或收窄对客表达边界，永不把专业研究输出削成简略、更不允许不出。**

例外仅两种：环境无法写文件（须报"文件生成阻塞"）、用户明确要摘要/纯聊天。**"覆盖但很薄"和注水同样是失败**。这与白泽"禁止跳过 workflow 阶段"的哲学完全同构——降级只能降 confidence，不能砍阶段。

### 2. 身份与用途分离
> **使用者身份不决定研究质量；使用目的只决定表达边界和交付形态。**

研究内核一致，对客版本按用途调整语气与交付物。

### 3. 研究台账（可审计性核心）
`原始数据 → 口径调整 → 计算/拆解 → 坐标 → 反面证据 → 证伪条件` —— 每条结论可回链到原始数据与计算路径。对应白泽 guardrails 的 `tier/nature` 溯源三要素 + `source_citations`，是该原则的落地模板。

### 4. 合规双版本
客户版**保留**证据支撑的方向性判断、依据、适用边界、反面证据、跟踪指标；但**严禁**买卖建议、目标价、操作指令、收益承诺、个性化资金与杠杆方案。与白泽"禁止输出具体买卖建议"护栏一致，额外提供了双版本渲染机制（专业 DOCX 默认；客户卡片/文案仅在用户请求时产出）。

### 5. 单一内核、三形态渲染
"一份内核、三形态渲染"——docx/card/PPT 全部渲染自同一分析内核；子模块不得覆盖渲染器/模板/样式/布局。

### 6. DOCX 生成链纪律
必须走唯一生成链 `scripts/docx_renderer.py`（从 `assets/docx-template.docx` 起稿 + `references/docx-style-tokens.json`）；**禁止模块直接 `Document()` 或硬编码字体/颜色/边距/表格宽度**；生成后跑 `scripts/audit_docx_visual.py` 审计（不渲染、不 PNG），失败仍可交付但必须列失败项并标注"未通过审计"。

### 7. 交付契约
每个交付物必须携带：数据截止日 + 确定度分级 + 免责声明；专业版输出触发"基于同一内核生成客户版"的提示。

## 五、可迁移机制清单

| # | 机制 | 应用到本项目 |
|---|------|------------|
| 1 | **研究台账**（原始数据→口径调整→计算/拆解→坐标→反面证据→证伪条件） | `docs/data-provenance.md` + 归因 `📋 信息源质量总览` 的落地模板；每条结论回链计算路径 |
| 2 | **最高不变量**（任何降级只能降置信度/收窄表达边界，绝不削薄输出） | 完整 workflow 禁止跳过阶段的哲学形式化：降级只能降 confidence，不能砍阶段 |
| 3 | **分位有效性检查**（value-trap guard：分位便宜≠便宜） | L1 价值维度增加分位漂移检查（近3年 vs 前5年 CAGR / 渗透见顶 / 商业模式 / 利率 regime） |
| 4 | **反向 DCF 隐含预期**（隐含长期增速 vs 实际增速 + 终值占比降强度 + 无目标价） | L1 估值维度补充前瞻性坐标；终值占比高→降结论强度 |
| 5 | **一票否决排雷**（审计非标/立案调查/违规担保/老千股史→直红不加权） | 军规硬规则 + L0 门禁的否决式设计（白泽已有 ST/流动性/200周均线否决，可扩展财务否决项） |
| 6 | **红旗库证据强制**（每雷必带公告证据；证据不足进"待核实"队列） | 诊断/归因的 `[UNSOURCED]` + `[DATA_GAP]` 显式声明机制 |
| 7 | **措辞红线**（禁 造假/必爆；M/Z→"进入统计预警区间"） | guardrails 禁止内容的形式化执行 |
| 8 | **合规双版本**（专业版 vs 客户版：保留证据化判断、剥离买卖动作） | "禁止具体买卖建议"护栏的渲染层实现：内核一致，对客剥离动作 |
| 9 | **时效门**（freshness-gate：超窗→结论强度封顶） | guardrails 时效性校验（STALE 排除 / 超期 confidence×0.7）的"强度封顶"表述 |
| 10 | **数据降级原则**（缺关键材料→弱结论，绝不降级交付物） | `[DATA_GAP]` 声明 + 对应维度权重下调，但不跳过阶段 |
| 11 | **单一内核多形态渲染**（一份内核、三形态） | `src/output/formatter.py` / `step_output.py` 分层输出：同一结果分专业/简报渲染 |
| 12 | **路由 + 接力**（fundamental 只做简版，深度问题接力到对应模块） | 用户交互 workflow 场景路由 + tactics 与 diagnose 的衔接设计 |
| 13 | **DOCX 生成链单一化 + 视觉审计脚本** | 回测/报告输出规范化：唯一渲染链 + 结构审计脚本 |
| 14 | **测试契约**（`tests/` 强制研究安全 + 响应 + 视觉契约） | 用测试锁死 guardrails 合规（输出必含信息源质量总览/置信度/免责声明） |

## 六、不直接借鉴 / 边界

- **不复制其 Agent Skill 安装路径为运行时依赖**——方法论进白泽代码/文档即可（与 Serenity 同策略）。
- **无量化评分管道**：该项目是"研究产出契约"模板，不提供多源行情聚合、因子计算、回测、仓位调度——这些仍是白泽自有的决策管道。
- **许可限制**：个人非商业学习免费；商业使用（客户交付/课程咨询/产品集成）需书面授权——仅借鉴方法论，不复制内容。
- **部分方法为美股样本校准**（M-Score/Z-Score），直接套用 A 股需按该项目方式标注"统计预警区间"而非裁决。
- **无 T+0 / 盘中时机**：本项目是研究/内容产出，不做日内买卖时机判断，与 tactics 无直接交集。

## 七、结论

rodya-caijing-studio 对白泽的最大价值不是某个数值模型，而是**研究产出的可审计性与合规契约**：(1) 研究台账（原始数据→口径调整→计算→坐标→反面证据→证伪条件）——是 guardrails 溯源三要素的可执行落地模板；(2) 最高不变量 + 时效门 + 数据降级原则——把"降级只能降 confidence 不能砍阶段"固化为不变量；(3) 一票否决排雷 + 红旗库证据强制——与军规硬规则/`[UNSOURCED]` 声明机制互相印证；(4) 估值方法论（分位有效性检查 + 反向 DCF 隐含预期）——可补充 L1 价值维度的前瞻性坐标；(5) 合规双版本 + 措辞红线——"禁止买卖建议"护栏的渲染层实现。
