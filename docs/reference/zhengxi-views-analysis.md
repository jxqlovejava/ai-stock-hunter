# zhengxi-views — 可溯源基金经理投研 Skill：原话佐证的方法蒸馏与言行对照

> 源码：https://github.com/lyra81604/zhengxi-views （MIT，1412★）
> 定位：一个可溯源的"基金经理观点库" Agent Skill——基于易方达基金经理郑希 2012–2026 全部公开观点原文语料 + 从语料蒸馏且**每条有本人原话佐证**的投资方法 + 全市场约 2.7 万只基金真实数据。能溯源问答、按他的框架给任意基金打分、言行对照（说的 vs 买的），语料外话题退守框架推演并显式声明，**绝不杜撰**。

与白泽的 `guardrails`（tier/nature 溯源、事实/解读/推测三分、`[UNSOURCED]` 声明）**同构且互补**：白泽管"数据点的溯源分级"，该项目管"**方法论本身的溯源**"——每条投资原则必须挂本人原话，每条回答必须分清"原话 / 推演 / 需核实"三种话。是四大师辩论、方法论参考文档、主题推演输出的可直接落地的诚实性模板。

## 一、架构（单 SKILL.md + references + scripts）

```
SKILL.md（路由 + 诚实底线 + 用法模式）
  ├── references/
  │   ├── corpus/            原文语料：定期报告57篇(2016-2026) + 基金经理手记15篇(2012-2025)
  │   │                      + 媒体报道4篇 + 简介/在任曾任基金清单 + corpus_index.json
  │   ├── method.md          投资方法框架：从语料蒸馏，每条附本人原话（核心资产）
  │   ├── scorecard.md       郑希框架六维评分卡（给任意基金打"风格契合度"分）
  │   ├── fund_data/         郑希 8 只基金（4在任+4曾任）精编快照：季度持仓.md/json + 净值业绩规模.md/json
  │   └── all_funds/         全市场 ~2.7 万只基金列表（代码/名称/类型/拼音）
  ├── scripts/
  │   ├── search_corpus.py   语料检索（命中段落+出处；--any 近义扩展 / --type 限类型）
  │   ├── fund_lookup.py     全市场基金名→代码解析（名称/拼音/代码/--type）
  │   ├── fetch_any_fund.py  按需抓任意基金持仓/净值 → fund_data_cache/（7天缓存，--force）
  │   ├── score_fund.py      评分一键入口：找代码+备数据+算机械指标 → 证据档案
  │   └── build_index.py / fetch_fund_data.py / build_fund_list.py  数据刷新链
  ├── evals/evals.json       3 条行为评测（溯源问答/前瞻应用/风格化点评），锁死"不杜撰"
  └── skill.yml + 跨平台部署（Claude / WorkBuddy / ima / ChatGPT / Gemini / Cursor）
```

**关键工程纪律**：脚本全部用绝对路径自定位数据、自带输出上限——调用时禁止 `cd &&`、管道、重定向、串行多命令（既避免人工确认弹窗，也防止模型自作主张加工输出）。对白泽 CLI 设计同样有参考价值。

## 二、三块根基与六大用法

| 根基 | 内容 | 支撑的能力 |
|------|------|-----------|
| 原文语料 | 全部公开观点原文，逐篇带日期/类型/出处 | ①溯源问答（引原文+自然出处，梳理观点演变） |
| 方法蒸馏 | method.md 每条原则附原话佐证 | ②讲解方法 ③语料外话题按框架推演（首句声明非本人观点） ④风格化点评（仿季报笔法，声明为模拟） |
| 真实数据 | 8 基金逐季持仓/净值/回撤/任职回报 + 全市场基金按需抓取 | ⑤言行对照（表态 vs 对应季度真实持仓） ⑥全市场查询对比 + 框架评分 |

**言行对照实例**：他 2026-06 采访说"光通信 2025 年二季度开始重仓"→ 查 001513 逐季持仓，2025Q2 起中际旭创/新易盛/源杰科技/光库科技确实集体进入前十大——言行一致。这是"观点"与"资金流"交叉验证的范式案例，与白泽交叉验证护栏（关键数据 ≥2 独立来源）精神一致。

## 三、方法内核：郑希投资框架（method.md 蒸馏）

**一句话框架**：从全球视野出发，找正在发生技术/需求变化、并因此"涨价（通胀）"的产业环节；在该环节里选 ROE 偏低、有修复弹性、流动性够的标的（偏好中小市值）；多维跟踪、逐步拟合、周期拼接；以"客观"为最高准绳，底层逻辑变坏就卖。

| # | 原则 | 要点（每条均有原话佐证） |
|---|------|------------------------|
| 1 | 景气度投资找"通胀" | 投产业景气周期而非"成长性"；先想清楚涨价从哪来；最偏爱**供给端创造需求**的科技通胀 |
| 2 | 科技公司本质是周期股 | 根本驱动力是技术迭代；多数是特定技术周期的阶段性受益者；**不对单公司形成信仰**，产业周期选择公司而非反之 |
| 3 | 全球视野+中国比较优势 | 先在全球坐标系判断技术/需求拐点 → 顺产业链找瓶颈 → 落到中国占优环节（光通信案例：AI Capex→传输分层→远距离靠光→中国光学占优） |
| 4 | 选股三件事 | (a)**流动性第一**（选错也能撤）；(b)**低ROE→高ROE 修复弹性**——只要两类"好的低ROE"：供求压制型 / 预先研发型；(c)多维跟踪（客户/竞对/供应链）；偏好中小市值 |
| 5 | 组合与风险 | 前十集中度常年 <50%；淡化仓位、**调行业比例**平衡风险；入场即想好退出机制；回撤观："抗跌来自找到能涨的品种" |
| 6 | 周期拼接/高换手/逐步拟合 | 复利=周期一次次拼接；**高换手是方法的一部分**；新方向早期反复交易拟合认知，看清再坚定加仓 |
| 7 | 客观为最高准绳 | 每个判断追问"是主观愿望还是客观证据"；重过程轻结果 |
| 8 | 卖出纪律 | 产业底层逻辑/竞争格局变坏就卖（2024 模型迭代放缓→先撤）；拥挤只做适度调整 |

**可操作流程**（7 步）：全球找变化 → 顺链找通胀环节 → 落中国比较优势 → 选标的（流动性+低ROE弹性+中小市值）→ 多维跟踪逐步拟合 → 组合分散+想好退出 → 客观校验、逻辑变坏就卖。

与白泽 serenity-bottleneck 的"找瓶颈环节"高度同构（通胀环节 ≈ 卡点环节），其"低 ROE 修复弹性"偏好是反共识选股信号，可补充 idea-generation 预设与 Alpha Lens 维度。

## 四、诚实性机制（核心借鉴面）

### 1. 三种话分离（回答的每句话都要能归类）
①**他的原话**（忠实引用 + 自然出处："他在 2026 年 6 月接受中国证券报采访时说"）②**按方法的推演**（首句加粗声明"不代表他本人观点"）③**需核实的事实**（无来源的公司/价格/数字标"需核实"）。读者必须一眼分清——这是 guardrails `fact/interpretation/speculation` 三性质在**生成侧**的强制落地。

### 2. 方法论本身的溯源
method.md 的根本区别："凭印象总结方法论" vs "每条附本人原话"。**凡蒸馏出的规则，必须能回链到原文段落**——直接适用于白泽四大师辩论（Buffett/Munger/... 原则目前依赖模型印象）与 docs/reference/ 方法论文档。

### 3. 语料外退守框架，不退守沉默
以前短板是语料没覆盖就回"未见"。正确做法：确认语料没有 → 首句声明非原话 → 用 method.md 框架推演给有内容的判断 → 拿不准的标"需核实"。对应白泽 `[DATA_GAP]` 哲学：降级只能降置信度，不能砍输出（与 rodya"最高不变量"互证）。

### 4. 内部记号不外泄
`[采2606]`、文件名、章节号、语料路径**禁止进入给用户的文字**；出处用人话自然带出。不报"共收录 N 篇"这类内部数字。

### 5. 数据窗口归属过滤
曾任基金的持仓覆盖整只基金历史（含其他经理任职季度）——言行对照前**必须先按郑希任职区间过滤**，别把别人的持仓算到他头上。通用的数据归属窗口纪律（同样适用于高管变更前后的业绩归因）。

### 6. 快照时效声明
持仓是季度快照非实时，引用必带季度与数据日期——与白泽 `data_freshness` 一致。

### 7. 评分卡定位守护
scorecard 六维（景气方向25 / ROE低位弹性20 / 全球比较优势15 / 流动性10 / 集中度与周期拼接15 / 业绩印证15）衡量的是"**与郑希风格的契合度**"而非基金优劣——防御/红利/纯债天然低分是正常的，必须讲清楚"低分≠差基金"。与白泽 `research_priority_score` 和管道分"并列、互不覆盖"的设计哲学相同：**每个分数都要锁住自己的语义边界**。

### 8. 行为评测锁死底线
`evals/evals.json` 把"区分原话与归纳""首句声明推演""不捏造数字"写成可执行评测——护栏不止靠提示词自觉，靠 eval 回归。

## 五、可迁移机制清单

| # | 机制 | 应用到本项目 |
|---|------|------------|
| 1 | **三种话分离**（原话/推演/需核实，首句声明） | 主题推演与归因输出的生成侧强制：推演段落首句必须声明，与白泽 nature 标签互为表里 |

| 4 | **语料外退守框架而非沉默** | `[DATA_GAP]` 场景的输出规范：声明缺口 → 按已有框架推演 → 标注需核实项 |
| 5 | **数据归属窗口过滤**（任职区间外数据剔除） | 高管/基金经理变更类事件的归因窗口纪律；timeline 结论演进的人物归属校验 |

| 9 | **近义词扩展检索**（光模块/光通信、算力/AI Capex 跨年份措辞漂移） | 资讯搜索/催化剂通道查询扩展：主题词表按年份维护近义变体 |
| 10 | **"找通胀环节"产业框架**（供给端创造需求 > 供需错配） | sector-research / serenity-bottleneck 的环节排序补充判据：该环节是否具备持续涨价属性 |
| 11 | **低 ROE 修复弹性**（供求压制型/预先研发型 vs 能力天花板） | idea-generation 预设与 Alpha Lens 增加反共识信号；与 PB-ROE 框架互补 |
| 12 | **脚本调用纪律**（绝对路径+输出自限，禁管道/串联） | 白泽 skill 文档中 CLI 调用规范的同款约束，减少权限弹窗与输出污染 |

## 六、不直接借鉴 / 边界

- **单一人物语料**：语料与评分卡围绕一个基金经理，不可泛化为"大师库"；白泽借鉴的是机制（原话佐证/三种话分离/言行对照），不是语料本身。
- **无决策管道**：不提供行情聚合、因子计算、军规、仓位调度、回测——这些仍是白泽自有管道；它的"评分"是风格契合度，不进入白泽评分体系。
- **数据为季度快照**：基金持仓按季披露，天然滞后，言行对照只能做到季度粒度，不适用于 T+0/日内。
- **第三方观点有立场**：基金经理公开表态有营销与合规滤镜，"言行一致"≠"观点正确"；作为归因输入时应按 T1/T2 级别降权。
- **许可**：代码 MIT；语料为公开披露内容，个人学习用途——仅借鉴机制与框架，不复制语料。

## 七、结论

zhengxi-views 对白泽的最大价值是**把"可信"做成可执行机制**而非口号：(1) 三种话分离（原话/推演/需核实 + 首句声明）——guardrails `fact/interpretation/speculation` 在生成侧的落地模板，可直接并入主题推演与归因输出规范；(2) 方法论逐条挂原话——治好"凭印象的四大师辩论"的潜在失真，方法论文档必须可回链；(3) 言行对照——观点表态与真实持仓/资金流的交叉验证范式，补强归因的证据链；(4) 评分语义守护与行为 evals——分数锁住语义边界、护栏用评测回归而非靠自觉。方法论层面，"找通胀环节 + 低 ROE 修复弹性 + 周期拼接"的景气度框架与 serenity-bottleneck 卡点分析互补，可作为行业研究的补充判据。
