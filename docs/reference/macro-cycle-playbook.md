# 宏观周期应对综合清单 — 达利欧五力 + 危机四步法（白泽化）

> 来源：① 青山海海《瑞·达利欧：先把下行保护做扎实，才有资格去追求上行空间（完）》（2026-08-08）② Eric 在搞钱《普通人怎么能一年内拥有千万资产？》（2026-08-06）
> 定位：一套框架回答三个问题——**潮汐朝哪个方向**（五力·慢变量）、**风暴中怎么守住**（现金纪律）、**抄底抄什么**（四步法·事件驱动）。
> 统一模型：五力是"背景潮汐"，四步法是"风暴应对链条"。先读潮汐，再守现金，确认信号后抄底，繁荣期卖出。
> 适用场景：单票归因、建仓判断、持仓体检、板块主题分析、市场高位/危机期仓位管理。不用于 T+0 日内择时。

---

## 一、统一模型与决策流程

### 1.1 两个框架的衔接

| 维度 | 五力框架（达利欧） | 危机四步法（Eric） |
|------|------------------|-------------------|
| 时间尺度 | 月度/年度（慢变量） | 危机周期（数年一轮） |
| 回答的问题 | 潮汐朝哪个方向 | 什么时候守 / 抄 / 卖 |
| 数据依赖 | 宏观 + 估值分位 + 政策 + 供应链 | Fed + 货币信用 + 信号确认 |
| 主要错误 | 方向对但时机早 | 时机对但方向错 |
| 共同前提 | **下行保护优先** | **先保现金后搏上行** |

### 1.2 统一决策流程（5 步闭环）

```
① 潮汐定位（五力）→ 判断当前周期位置、哪股力量在运动
② 市场位置（泡沫仪 A 股代理）→ 估值分位 / 股债性价比 / 杠杆拥挤度
③ 危机预警（信用利差 / 10Y-2Y 倒挂 / 全球共振）→ 触发现金纪律
④ 抄底信号确认（放松信号 + 估值低位 + 质量真实，三者齐备）→ 分批建仓
⑤ 繁荣期卖出（估值高 + 拥挤度 + 盈利修正见顶）→ 清杠杆、落袋、等下一轮
```

> ①⑤是慢循环（数月-数年），③④是快事件（危机窗口）。**②③④ 之间以"信号确认"为界，禁止预测拐点**。

### 2.3 市场位置检查表（泡沫测量仪 → A 股代理）

> 达利欧泡沫仪（1900 至今）当前读数 ≈ 1929/2000 水平的 **75%**："说不准三年还是十年，但以这个估值长期持有大概率没好结果。"A 股用代理指标组合逼近。

**数据源**：`sentiment/signals.py`（市场宽度/两融/量比/涨停池/ETF 波动率）、全 A PE/PB 分位。

- [ ] 全 A / 沪深300 PE、PB 历史分位
- [ ] 股债性价比（ERP）：沪深300 股息率 / PE 倒数 vs 10Y 国债
- [ ] 杠杆拥挤度：两融余额 / 成交额 / 换手率
- [ ] 散户情绪：新开户 / ETF 申赎 / 涨停池家数 / 破净率
- [ ] 估值动量双高（`valuation_or_momentum` 是否触发）

| 市场位置读数 | 动作 | 对应白泽机制 |
|-------------|------|-------------|
| 分位 < 30% | 正常建仓，仓位上限可更高 | 仓位调度正常档 |
| 50%-70% | 中性，降低高估值标的权重 | 军规估值规则前置 |
| > 70% | **分散优先于择时**：构建不相关组合，战术降杠杆，禁止满仓赌拐点 | 仓位调度降档 + 风控 L4 |
| > 85% + 杠杆拥挤 | 单票 max 仓位下调，ATR 止损收紧 | 军规 CRITICAL 组合 |

> **关键纪律**：泡沫仪给位置不给拐点。**不因高水位全换现金坐等崩盘，也不因低水位满仓豪赌**。

### 2.5 债务周期阶段定位 + 美元潮汐传导（达利欧框架落地，新增）

**数据源**：`src/macro/debt_cycle.py`（`python -m src macro` 输出"债务周期阶段 + 美元潮汐"）。

**债务周期四阶段**（达利欧叙事映射真实数据）：

| 阶段 | 判据（白泽可观测） | 含义 | 应对 |
|------|-------------------|------|------|
| 加杠杆/信用扩张 | 信贷脉冲 > +1，或 M1-M2 剪刀差走阔 > +1 | 借钱生产/消费上升 | 权益相对受益，跟踪信贷脉冲何时转负 |
| 资产泡沫累积 | 信贷脉冲 ≥ +2 且社融增速 > 名义GDP+1.5 | 投机性债务占比上升 | 警惕加息刺破，控制杠杆，勿追高估值泡沫 |
| 去杠杆/信用收缩 | 信贷脉冲 < -1，或 M1-M2 倒挂 < -1，或 DR007 偏高 | 全社会还债，支出收缩 | 守现金优先，高杠杆/题材股承压 |
| 中性 | 信号不足 | — | 不作方向性判断 |

> 判据优先级：信贷脉冲 > 社融 vs 名义GDP > M1-M2 剪刀差 > DR007。数据缺失标记 `[DATA_GAP]`，置信度下调，不做强判断。

**美元潮汐传导链**（拉美/亚洲金融危机教训）：
`美联储加息/美债利率↑ + 美元指数↑ + 人民币贬值 → 北向资金承压 → A股估值受压制`
- 白泽抓取：美债10Y（`bond_zh_us_rate`）、美元兑人民币（`currency_boc_sina`）；美元指数 DXY 无稳定 akshare 源 → `[DATA_GAP]`，用 USDCY 趋势代理。
- 判定：美债10Y 20日 +15bps 或 USDCY 20日 +1% → outflow（流出）；反向 → inflow（流入）。

**通缩型 vs 通胀型危机二分**（决定"守现金" vs "抄底"的策略）：

| 维度 | 通缩型（1929/日本/2008） | 通胀型（拉美/亚洲/魏玛） |
|------|--------------------------|--------------------------|
| 债务币种 | 本币债为主 | 外币债或本币信用崩溃 |
| 央行工具 | 能印钞放水，可止崩盘 | 印不了外币，越印贬值越快 |
| 危机表现 | 资产跌、物价跌、通缩 | 本币贬值、物价飞涨、恶性通胀 |
| A股应对 | 留足流动性，等放水确认后抄**核心优质**资产 | 本币资产承压更重，优先避险/现金 |

## 三、危机四步法检查清单（风暴应对）

### 3.1 四步法映射表

| 四步法 | 白泽阶段 | 核心动作 | 可执行入口 |
|--------|---------|---------|-----------|
| ① 等待危机（周期性必然出现） | 宏观监控 | 周期定位 + 预警信号 | `market`（美股隔夜+情绪+货币信用）/ `macro` |
| ② 加息末端留现金、不投大钱 | 仓位调度 + 现金管理 | 降杠杆、储备足额现金 | `positioning` 仓位上限档位 |
| ③ 放水确认后抄底**核心优质**资产 | 军规 + `diagnose` | 区分"错杀" vs "风口猪" | 军规全流程 + Alpha Lens |
| ④ 繁荣期卖出、降负债 | 仓位调度 + 止盈 | 高位落袋、清杠杆 | ATR 止盈 + 拥挤度监控 |

### 3.2 阶段 A：周期定位与预警（"等待危机"）

**数据源**：`get_us_overnight()` / `get_global_market()`（S&P500/Nasdaq/Dow/日经/恒生/KOSPI）、`cross_asset.py`（10Y 国债/10Y-2Y 利差/实际利率/信用利差/USD-CNY/铜油）、`monetary_credit.py`。

- [ ] 货币-信用象限在哪格？
- [ ] 信用利差（AA-国债）是否走阔？（信用收缩前兆，领先资产暴跌）
- [ ] 10Y-2Y 利差是否倒挂？（危机预警经典指标）
- [ ] 实际利率（10Y-CPI）方向
- [ ] 美股隔夜指数动量：高位区还是已回调？
- [ ] 全球共振：日经/恒生/KOSPI 是否同步走弱？
- [ ] 高杠杆行业（地产/基建/高负债制造）是否现违约/展期信号？

| 信号 | 动作 |
|------|------|
| 信用利差走阔 + 倒挂 + 全球走弱 | 进入"危机预警"模式，转阶段 B |
| 象限转紧缩-收缩 | 降高估值成长权重 |
| 单一市场独跌（无共振） | 归因区域性事件，不升级系统性 |

### 3.3 阶段 B：现金纪律（"加息末端留现金"）

**数据源**：`get_us_overnight()`（美股位置代理）；⚠️ **Fed 利率无白泽直连源**，需外部监控，标 [DATA_GAP]。

- [ ] Fed 加息阶段：最激进期 / 近尾声 / 中性利率区？⚠️ [DATA_GAP] 外部
- [ ] 美股位置（代理）：历史分位高位 → 该"抛高价资产储备现金"
- [ ] 组合现金比例 ≥ 危机预案阈值？
- [ ] 杠杆暴露：两融/融资盘持仓比例，高杠杆标的已减持？（`quality_max_debt_to_equity`）
- [ ] 现金流稳定性：日常收入/分红是否充足

| 信号 | 动作 | 对应机制 |
|------|------|---------|
| Fed 加息到顶并持续（外部） | 降仓位上限档位，储备现金 | `positioning` 降档 |
| 美股高位 + 杠杆拥挤 | 减持高杠杆/高估值，换现金 | `valuation_or_momentum` weight_cut 0.5 |
| 现金充足 + 放松信号未现 | **按兵不动**，禁"怕错过"提前抄底 | 军规纪律优先 |
| [DATA_GAP] Fed 利率不可用 | 用美股隔夜 + 利差代理，降置信度 | 质量加权 |

> **阶段 B 是整份清单的下行保护**。宁可踏空，不可套牢。

### 3.4 阶段 C：放水确认后抄底核心资产（"抄底优质资产"）

**数据源**：`monetary_credit.py`（放松信号）、`cycle_valuer.py`（席勒 PE/PB 分位）、军规 + `diagnose`、Alpha Lens。

**核心二分：错杀的优质资产 vs 风口的猪。**（错杀=风险偏好降低误杀；风口猪=信用扩张/超发吹起，内在价值不高。）

- [ ] **放松信号已确认**？社融拐头 / 降息 / 降准 / 财政发力（信贷脉冲向上）——非"猜测要放水"
- [ ] **估值低位确认**？席勒 PE/PB 分位处历史低位
- [ ] **军规全过**？尤其 CRITICAL：`quality_audit_opinion`、`liquidity_min_turnover_wan`、`momentum_consecutive_limit_down`（**连续跌停已排除的禁止接刀**）
- [ ] **质量真实**？ROE 持续质量 vs 一次性；盈利修正方向
- [ ] **稀缺性**：是否"富人一定喜欢"的核心资产？（壁垒/牌照/品牌/技术垄断）
- [ ] **杠杆纪律**：抄底是否动用杠杆？→ 军规负债红线前置（`quality_max_debt_to_equity`）

| 信号 | 动作 |
|------|------|
| 放松信号未确认 | 禁止抄底，现金继续等待（不预测拐点） |
| 估值低位 + 军规全过 + 质量真实 | 分批建仓，非一把梭 |
| 估值低位但质量存疑/风口猪 | 降级观察，不建仓 |
| 连续跌停/财务红线 | 一票否决，绝不接刀 |
| 动用杠杆抄底 | 军规拦截 + 仓位强制降档 |

> **信号是确认出来的，不是猜出来的**。抄底前提 = 估值低位 且 放松信号确认 且 质量真实，三者缺一不可。

### 3.5 阶段 D：繁荣期卖出、降负债（"高位卖，重复 N 次"）

**数据源**：`cycle_valuer`（估值分位）、`game-theory`（拥挤度）、`earnings_revision`（盈利修正）、ATR 止盈。

- [ ] 估值分位是否回到高位？
- [ ] 板块拥挤度：`CROWDED` 乘数是否触发（四大师 polarized）？
- [ ] 盈利修正是否见顶回落？
- [ ] ATR 动态止盈是否触发？
- [ ] 卖出后是否按计划降杠杆、保留利润？

| 信号 | 动作 |
|------|------|
| 估值高位 + 拥挤度触发 | ATR 止盈 + 分批卖出，清杠杆 |
| 盈利修正见顶 | 降持仓权重，转防御 |
| 一轮完成 | 现金回笼，回归积累，等下一轮 |

### 3.6 核心原则落地表

| 原则 | 白泽落地 | 对应机制 |
|------|---------|---------|
| 资产价格是货币现象 | 只认"放松信号已确认"，不预测 | `monetary_credit` 信贷脉冲/社融拐点 |
| 只抄优质核心资产 | 错杀 vs 风口猪二分 | Alpha Lens + 军规 + 质量审查 |
| 未来卖给富人 | 稀缺性/壁垒/席位 + 北向 | `game-theory` |
| 先保现金后搏上行 | 阶段 B 是下行保护，先于阶段 C | 仓位调度 + 军规 |
| 过程漫长、考验眼力 | 慢变量纪律，禁 T+0 化 | 统一流程 ①⑤ 慢循环 |

## 四、统一综合检查清单（一页速查）

### 4.1 决策流程快筛（30 秒）

```
① 潮汐：货币信用象限？估值分位？哪股力量在运动？
② 市场位置：PE/PB 分位？股债性价比？杠杆拥挤度？
③ 危机预警：信用利差走阔？10Y-2Y 倒挂？全球共振走弱？
   → 是：转入现金纪律（阶段 B）
④ 抄底信号：放松信号已确认？估值低位？军规全过？质量真实？
   → 三者齐备才分批建仓，禁用杠杆
⑤ 卖出纪律：估值回高 + 拥挤 + 盈利修正见顶 → ATR 止盈、清杠杆、等下一轮
```

### 4.2 完整检查清单（归因 / 建仓 / 持仓体检通用）

**① 潮汐判断（背景）**
- [ ] 货币信用象限：宽松-扩张/宽松-收缩/紧缩-扩张/紧缩-收缩
- [ ] 社融 vs 名义GDP、信贷脉冲方向
- [ ] 市场估值分位 + 股债性价比 + 杠杆拥挤度

**② 标的定位（五力哪个维度在运动）**
- [ ] 债务货币：高杠杆/长久期暴露？利率敏感？
- [ ] 价值观分裂：强监管区？政策顺风/逆风？
- [ ] 大国博弈：地缘暴露？国产替代真/假？
- [ ] 自然：供给冲击在不在路上？
- [ ] 创造力：渗透率 S 曲线哪段？技术过时风险？

**③ 下行保护（先于上行追求）**
- [ ] 军规全部通过（尤其 CRITICAL：审计/流动性/连续跌停）
- [ ] 单票仓位 ≤ 市场位置允许上限；组合相关性检查（分散优先于择时）
- [ ] ATR 动态止损已设置；现金比例 ≥ 危机预案阈值
- [ ] 禁用杠杆抄底；高杠杆持仓已在加息末端减持

**④ 上行空间（通过保护后）**
- [ ] Alpha Lens 三维：价值/质量/Alpha 协同为正
- [ ] 盈利修正因子方向；渗透率加速期确认
- [ ] 估值 vs 能力（非估值 vs 热门）；稀缺性/壁垒核查

## 五、风险与边界（护栏）

1. **慢变量纪律**：五力是月度/年度背景框架，**禁止**用于 T+0 日内择时或当日涨跌直接归因（当日归因仍走 `stock-attribution` 3 阶段 + 时效性校验）。
2. **不替代硬规则**：五力 + 四步法回答"潮汐与风暴"，军规/财报/准入回答"船本身质量"。顺序：先硬规则，再宏观框架。
3. **杠杆抄底 vs 军规红线**：Eric 文章建议"负债加杠杆抄底"，本项目军规对高杠杆一票否决（`quality_max_debt_to_equity`）。**立场：可用现金抄底，禁用杠杆**——杠杆放大下行，恰恰破坏"下行保护"前提。
4. **择时预测器陷阱**：四步法依赖踩准拐点，但白泽原则是"泡沫仪给位置不给拐点"。只在**信号确认后**行动（阶段 C 前置），禁止"猜什么时候崩/什么时候涨"。
5. **证据要求**：宏观判断必须落到白泽可观测数据（社融/信贷脉冲/估值分位/监管记录/订单），空泛的"国运""周期"表述一律标 [SPECULATION] 或 [UNSOURCED]。
6. **数据缺口**：Fed 利率无直连源 → 标 [DATA_GAP]，用美股隔夜 + 利差做代理，置信度降级，不得脑补。其他代理数据拉取失败同理。
7. **时效**：地缘/自然事件按 12h 时效规则处理，过期标 [STALE] 排除出主因。
8. **不预测、只应对**：危机是否来、何时来属于 [SPECULATION]；只在"预警信号 → 现金纪律 → 放松确认 → 抄底"链条上做确定性动作。
