## 一、综述

### 整体质量评估

- **可信度分布**：高（≥0.6）11 篇、中（0.4–0.59）9 篇、低（<0.4）10 篇。整体中低——约 1/3 为无实质内容的提问/钩子帖或营销引流（doc 01/09/14/18/20/26），真正有框架价值的高可信篇集中在仓位管理（doc 15/25）、散户生存法则量价系列（doc 19/21/22）、量化闭环（doc 13）、名人采访（doc 24）。
- **主题分布**：技术分析/短线战术最多（11 篇），仓位管理/风控（6 篇），量化/系统化交易（4 篇），投资理念/交易心理（5 篇），基本面/宏观/市场结构（5 篇）。
- **最大共性（跨文档一致，可信度互证）**：仓位纪律与风控是所有高可信文档的共识——「先活下来」「单笔风险预算 2%」「不追高」「机械执行纪律」。多个独立来源指向同一结论，是 30 篇中最可信、最值得落地的部分。
- **最大缺陷**：零回测、零统计胜率。全部 30 篇中没有任何一篇提供可核验的回测/实盘统计（唯一带论文数字的 doc 11 也被告知样本外衰减），因此所有技术指标类内容只能作为「启发式过滤器」而非「触发信号」。

### 核心发现（5 条）

1. **风控纪律跨文档高度一致，可直接固化为硬约束**：单笔亏损 ≤ 总资金 2%、单日亏损 ≤ 6% 熔断、单票仓位上限、连续亏损冷静期——在 doc 15/25/12/13/02/05 六篇独立来源中反复出现，应作为白泽 L3/L4 的默认参数，而非建议值。
2. **技术信号"趋势优先 + 多层过滤"是散户生存法则系列（19/21/22/28）自洽闭环的结论**：均线定方向、MACD 定动能、量能验真伪、市场状态（趋势/震荡）前置判定。金叉死叉/均线突破脱离趋势与位置单独使用必失效——这是对现有 tactics MACD+KDJ 五法最重要的修正方向。
3. **doc 13 量化闭环与白泽 learner 架构同构，是最具直接落地价值的一篇**：软硬参数分离 + clamp 兜底、错误类型分类复盘、置信度映射仓位、双信号源"不冲突才开仓"，四点均可映射到白泽现有护栏。
4. **投资理念层（12/15/25/30/29）收敛于"敬畏有效性 + 找失效 Alpha"**：不追已 price in 的共识信息、一手信息优先、情绪反向纪律、证据→概率→仓位。对应白泽 Alpha Lens 预期差识别与 sentiment 恐慌套利，可作为检查项而非信号。
5. **制度适配是 A 股落地的第一性约束**：近半数文档基于美股/加密（T+0、可做空、无涨跌停），其做空/剥头皮/日内平仓策略在 A 股 T+1 + 涨跌停下**必须重写执行层**，只能迁移理念与过滤逻辑。

## 二、分主题高价值结论

### 1. 量化 / 系统化交易

**核心可借鉴内容**：
- **五阶段闭环架构**：感知 → 决策 → 执行 → 复盘 → 更新。决策层硬规则「技术观点与新闻观点冲突时不允许开仓，动作只能 hold/close」；复盘层错误类型分类 `chased_move / ignored_news_conflict / stop_too_tight / stop_too_wide / overleveraged / held_too_long`；更新层参数全部 clamp 到人工设的 [下限, 上限]（doc 13，可信度 0.6）。
- **置信度映射仓位**：`size_pct = base_pos_pct × clamp(confidence/100, 0.4, 1.0)`；置信度低于阈值放弃开仓（doc 13）。
- **硬软参数分离**：AI/LLM 只能微调软参数（仓位%、止损%），硬边界（最大仓位、最大加仓次数、硬止损）由代码层强制——与白泽"仅 SignalWriter 可写 + L4 风控硬约束"同构（doc 13）。
- **结构化快照优于原始数值**：指标按 trend/momentum/volatility/volume 分组 + 布尔字段（如 `macd_hist_rising`），而非原始数值直接喂模型（doc 13）。
- **单指标极简策略 + 强制日内了结 + 盈亏比优先**：VWAP 策略 43% 年化（2018–2023 QQQ，夏普 2.1），但只有约 17% 交易盈利，靠盈亏比而非胜率取胜（doc 11，可信度 0.5）。
- **模型纪律**：100% 模型驱动、禁止人为 override；「不依赖单一必胜指标，靠大量细微异常聚合」（Jim Simons 访谈，doc 24，可信度 0.75，本篇最高）。
- **特征回测-筛选流水线**：每个候选因子须过"长周期历史回测→有效才入池"门槛（doc 24）。
- 资源清单：`github.com/paperswithbacktest/awesome-systematic-trading`（97 库/40+ 策略/55 书，doc 20，可信度 0.7，仅作开发层选型参考）。

**关键文档来源**：doc 13（0.6）、11（0.5）、24（0.75）、20（0.7）。

### 2. 技术分析 / 短线战术

**核心可借鉴内容**：
- **量价是过滤器不是预测器**：放量≠资金流入（每笔成交同时有买卖双方）；放量只证明激烈交锋，假突破常发生在成交量最大时。真突破三条件：收盘站稳 / 后续续涨 / 回踩缩量守。三类被量能过滤的错误：不在放量下跌中抄底、不把缩量反弹当反转、不追无量突破（doc 19，可信度 0.65）。
- **MACD 双层过滤**：均线定方向、MACD 定动能。金叉仅在 MA20/MA50 多头趋势时才计入买入信号；死叉不直接卖出，须等均线转弱/趋势破坏才确认卖出。逆趋势金叉是低权重信号（doc 21，可信度 0.65）。
- **市场状态前置判定**：先分趋势市/震荡市（缠论中枢、均线斜率、ADX），仅趋势市启用金叉买/死叉卖；震荡市降权或忽略（doc 22，可信度 0.65）。
- **MACD 速度/背离维度**：价格创新高而 MACD/DIF 未同步创新高 = 顶背离 = 上涨减速预警（降仓/收紧止损），真正卖出以跌破 MA20/MA50 为准；连续涨停/跌停标的 MACD 失真应排除（doc 28，可信度 0.55）。
- **跨周期过滤 + 收线确认**：信号级（如 5min）与过滤级（15min/60min/日线）分层确认；等 K 线收线后第二根才进场，防止未定型信号反复横跳（doc 07，可信度 0.35，方法可取参数自定）。
- **MM 等距投影目标位**：震荡区间/推动段高度向下一方向翻一倍作止盈参考区，目标位附近分批止盈 + 不追单，盈亏比 ≥1:1 门槛，止损放影线外（doc 06，可信度 0.4）。
- **均线分层体系**：20/30 日管波段、60 日管大级别、120 日（半年线）管中长期、250 日管牛熊分界；120 日向下不逆势、30 日破位离场、一阳穿三线为主升启动（doc 16，可信度 0.35）。
- **均线破位质量检查**：放量砸破均线=真出逃；缩量跌破=多为洗盘、后面大概率修复。但单边下跌中缩量阴跌同样是真破位，须叠加趋势方向（doc 27，可信度 0.4）。
- **量比+换手率启发式**（doc 08，可信度 0.25，仅作资金活跃度特征）：量比 >5 圈活跃股 → 换手率 3%-8% 二次过滤 → 组合定启动/加仓/出货；换手 >5% + 量比 <2 = 资金撤离回避。
- **6 种止跌 K 线形态**（长阳 >5%、长下影、刺透、看涨吞没、孕线、晨星）+ 必须次日确认（doc 23，可信度 0.45）。
- **VWAP 日内分水岭**：开盘第一分钟 K 线收盘相对 VWAP 方向定开仓方向，收在另一侧平仓（doc 11，可信度 0.5）。
- **前复权统一**：除权缺口会干扰技术指标，数据管道应统一前复权（doc 05，可信度 0.45）。

**关键文档来源**：19（0.65）、21（0.65）、22（0.65）、28（0.55）、06（0.4）、07（0.35）、16（0.35）、27（0.4）、08（0.25）、23（0.45）。

### 3. 仓位管理与风控

**核心可借鉴内容**：
- **单笔最大亏损 ≤ 总资金 2%**：按"止损价−入场价 × 头寸"反推最大仓位，使单笔风险 ≤ 2%（doc 15/25，均 0.7）。
- **单日累计亏损 6% 熔断**：三次 2% 止损 = 6%，达 6% 当日强制停止交易至次日（doc 25，可信度 0.7）。
- **资金四账户分层**：生存 20% + 机会 30%（平时货基，仅历史级机会动用）+ 长线定投 30% + 短线 20%（最多同持 5 个标的）（doc 15，可信度 0.7）。
- **应急金前置**：先预留 1 年家庭支出，用年度结余做投资本金（doc 15）。
- **连续亏损冷静期**：连续踩坑即暂停交易/熔断，重新梳理后再进场（doc 15）；对应 doc 12 的"亏损后禁止报复性加仓"军规候选。
- **334 仓位法**：30% 底仓 + 30% 机动 + 40% 现金；首次开仓永不满仓；单票上限 20%-30%（doc 05，可信度 0.45）。
- **亏损-回本不对称表**：亏 10% 需涨 11%、亏 30% 需涨 43%、亏 50% 需涨 100%、亏 90% 需涨 9 倍回本——用于投资者教育/画像输出（doc 25）。
- **机会资金纪律**：为恐慌套利等极端机会预留现金仓位（doc 15/30）。

**关键文档来源**：15（0.7）、25（0.7）、12（0.7）、13（0.6）、05（0.45）。

### 4. 投资理念与交易心理

**核心可借鉴内容**：
- **五次认知蜕变**：概率思维（只做高胜率、接受亏损）→ 戒报复性交易 → 敬畏系统严格执行 → 情绪绝缘 → 成为系统信徒。核心主张"交易不是预测，是在概率中寻找优势"（doc 12，可信度 0.7）。
- **敬畏市场有效性**：公开刷屏信息已被 price in，看到新闻先问"价格已计入多少"；Alpha 来自市场失效三处——误读逻辑 / 夸大风险 / 尚未意识到的主线（doc 30，可信度 0.5）。
- **一手信息优先**：财报、电话会、订单、产业链原始信息、管理层措辞 > 任何博主转述；机会来自"理解差"而非"信息差"（doc 30）。
- **三层归因框架**：下跌先分执行层（买法）/ 资本配置层（仓位排队）/ 投资逻辑层（核心假设）——避免把执行问题升级成逻辑问题，也避免用短期回调掩盖逻辑破裂；越往上推翻所需证据越多（doc 29，可信度 0.55）。
- **学习路径六阶段**：基本面 → 公司分析 → 技术面 → 交易纪律 → 小仓实战复盘 → 资产配置（doc 10，可信度 0.6）。
- **定投纪律/房贷纪律**：到点必投、下跌多买、熬过沉默期；但文中纳指 10-12% 年化假设不适用 A 股单一指数（doc 03，可信度 0.7）。
- **"先活下来 > 赚钱"**：情绪管理（赚钱急跑、亏钱死扛）是亏损主因；等市场把钱送到面前再伸手接（doc 02，可信度 0.4）。
- **适配性优先**：方法必须与使用者能力圈/风险偏好匹配，而非追求万能圣杯（doc 18，可信度 0.25，仅理念）。

**关键文档来源**：12（0.7）、30（0.5）、29（0.55）、03（0.7）、10（0.6）、02（0.4）。

### 5. 基本面 / 宏观 / 市场结构

**核心可借鉴内容**：
- **三维度选股框架**：宏观周期 → 行业生命周期（初创/成长/成熟/衰退）→ 公司质地（商业模式/护城河/估值），"选股先选行业"——与白泽 Serenity 先层后票一致（doc 05，可信度 0.45）。
- **四模块交易体系**：选股有边界 + 交易有纪律（应对跟随而非预测）+ 仓位有分配 + 风控有底线；四大法则"仓位管理 > 选股、止损纪律 > 预测、逻辑验证 > 内幕、等待 > 操作"（doc 05）。
- **春夏秋冬行情节奏**：春（温和小涨→观察）→ 夏（普涨放量→重仓）→ 秋（天量补涨→减仓）→ 冬（炸板量缩→空仓）——对应主题生命周期（doc 05）。
- **"预期的栏杆会移动"→ 预期差框架**：业绩指引上修但股价不涨 = 预期已跑更远 = 预期差钝化信号；跟踪"利好出来股价怎么走"（doc 29）。
- **AI 叙事三阶段切换**：早期奖励想象力 → 中期奖励订单/收入确认 → 后期奖励兑现的利润/自由现金流/EPS——市场换考卷时旧答案失效（doc 29）。
- **跨市场传导时间差**：产业链现货价格异动（华强北 MLCC 囤货）→ 海外龙头（村田）→ A 股对标（风华高科）滞后约 2 周，可作供应链领先信号；中美联动时间差 2-4 周（doc 04，可信度 0.3，理念可借鉴）。
- **历轮 A 股牛市归因框架**：政策 + 资金 + 货币（降准降息）三维驱动，可作大盘行情阶段识别输入（doc 04）。

**关键文档来源**：05（0.45）、29（0.55）、04（0.3）、30（0.5）、17（0.3，方法论）。

## 三、对"白泽"系统的落地建议（按模块）

> 标注 [高][中][低] 优先级；「来源」后括号为可信度。操作层可直接编码，理念层仅作指导原则。

### 军规 doctrine

- **[高] 新增军规：亏损后禁止报复性加仓**——单笔亏损后当日禁止追加仓位；盈利后禁止盲目重仓追高（来源 doc 12，0.7）。
- **[高] 新增军规：放量下跌中禁止盲目抄底**——并入反操纵/抄底禁入检查（来源 doc 19，0.65）。
- **[高] 新增军规：信息面冲突即禁止开仓**——技术信号与基本面/政策面冲突时，动作强制为 hold/close（来源 doc 13，0.6）。
- **[中] 强化"空头趋势禁抄底"**：120 日线向下 / 200 周均线破位后，反弹减仓而非逆势抄底（来源 doc 16/17，0.35/0.3；与现有 r035/r036 方向一致，仅作周期层补充确认）。
- **[中] 逆趋势 MACD 金叉记为低权重信号**：避免多头动能维度误加分（来源 doc 21，0.65）。
- **[低] 追高拦截**：目标位（MM 投影）附近不追单、大波幅 K 线放弃（来源 doc 06/07，0.4/0.35）。

### 多维诊断 diagnosis / tactics

- **[高] tactics 技术 6 维加入"市场状态前置判定"**：先用缠论中枢/均线斜率/ADX 分趋势市 vs 震荡市，仅趋势市启用金叉/死叉/均线突破信号；震荡市信号降权或忽略（来源 doc 22，0.65）。这是对现有 MACD+KDJ 五法最关键的修正。
- **[高] 双层过滤框架落地"均线定方向 + MACD 定动能"**：MACD 金叉须 MA20/MA50 多头（至少 MA20 向上）才计入买入；死叉不直接触发卖出，须均线走弱/趋势破坏联动确认（来源 doc 21，0.65；doc 28，0.55）。
- **[高] 新增 MACD 顶背离维度**：价格创新高 + MACD/DIF 未同步创新高 → 标记上涨减速、降仓/收紧止损；连续涨停/跌停标的排除或降权（来源 doc 28，0.55）。
- **[高] 量价过滤器**：新增"放量滞涨（长上影）"为减仓/出场预警；"假突破 4 检测"（盘中破位收盘跌回 / 放量不涨留长上影 / 突破当天放量后续不新高 / 回踩放量重新跌破）作为突破信号的否决过滤器；"缩量反弹=卖压缓解≠反转"降权（来源 doc 19，0.65）。
- **[中] 真突破三条件作为二次确认**：收盘站稳 / 后续续涨 / 回踩缩量守——叠加到缠论买点或均线突破确认步骤（来源 doc 19，0.65）。
- **[中] 均线破位质量检查**：跌破 20/60 日线区分放量（真出逃，更高止损权重）vs 缩量（多为洗盘，趋势未破坏证据）；A 股放量跌停破位信号极强应优先执行（来源 doc 27，0.4）。
- **[中] VWAP 日内分水岭**：纳入 T+0 日内时机，作盘中趋势判定基准（VWAP 上方偏多、下方偏空）；仅取"开多 + 日内了结"半边，涨跌停标的剔除（来源 doc 11，0.5）。
- **[中] 跨周期过滤 + 收线确认**：信号级（日线）与过滤级（周线/60min）分层；"须待分时 K 线收线后再决策"加入 T+0 规则（来源 doc 07，0.35）。
- **[中] 量比 + 换手率作为资金活跃度启发式特征**：进入 admission/候选池过滤（量比 >5、换手 3%-8%）；"换手 >5% + 量比 <2 = 资金撤离"作动能衰减辅助检查项；标记 [SPECULATION]，不单独触发信号（来源 doc 08，0.25）。
- **[中] MM 等距投影目标位**：加入 tactics 止盈设定与 diagnosis 技术维度，与缠论中枢量幅并列；目标位附近分批止盈（来源 doc 06，0.4）。
- **[低] K 线止跌信号库 + 强制次日确认**：长阳 >5%、长下影、刺透、看涨吞没、孕线、晨星作"止跌候选"，须次日确认 + 板块热点 + 量价过滤后才入反弹候选，限定仓位上限（来源 doc 23，0.45）。
- **[低] 均线分层口诀化**：20/30/60/120/250 日线分层语义，与现有均线维度合并（来源 doc 16，0.35）。
- **[高] 数据管道统一前复权**：避免除权缺口干扰技术指标（来源 doc 05，0.45）。

### 仓位调度 positioning

- **[高] 单笔风险预算 ≤ 2% 固化为硬上限**：每笔信号按"止损价−入场价 × 头寸"反推最大仓位；A 股 T+1 下止损位距离受涨跌停限制，需前置到买入前风控（来源 doc 15/25，0.7）。
- **[高] 置信度连续化仓位缩放**：`仓位 = 基础仓位 × clamp(confidence, 0.4, 1.0)`——与白泽"confidence <0.6 不进 L3"的分制思想互补（来源 doc 13，0.6）。
- **[中] 证据→概率→仓位梯度**：单一信号=观察仓；多证据互验=正常仓；核心假设兑现 + 价格确认=高确信仓；顺序固定"证据变化→更新概率→概率变化→仓位才变"（来源 doc 29，0.55）。
- **[中] 持仓分散度约束**：单票上限 20%-30%、最多同持 5 个标的、首次开仓永不满仓（来源 doc 15/05，0.7/0.45）。
- **[中] 现金纪律**：334 仓位法（30 底仓 + 30 机动 + 40 现金）或 40% 现金风格参数，为恐慌套利/极端机会预留"机会资金"（来源 doc 05/15/30，0.45/0.7/0.5）。
- **[低] 定投纪律 / 下跌多买**：仅适用于宽基指数定投场景，需对沪深300/中证500 做波动与回撤压力测试，下调年化假设（来源 doc 03，0.7）。

### 风控 risk_control

- **[高] 单日 6% 熔断（2%×3）**：当日已实现+浮亏 ≥ 6% 时暂停当日剩余信号输出/交易，强制冷却至次日（来源 doc 25，0.7）。
- **[高] 连续亏损冷静期熔断**：连续 N 次止损信号后暂停自动信号输出或下调信任权重（来源 doc 15/12，0.7）。
- **[高] 硬止损 + 软参数 clamp 分离**：硬边界（最大仓位、最大加仓次数、硬止损、单票敞口上限）由代码层强制，LLM/分析 Agent 只能调整软参数区间；超限强制削减（来源 doc 13，0.6）。
- **[中] 行为偏差监控**：检测"亏损后快速追单加仓 / 要求放宽止损 / 回本执念"行为，触发风险提示或降级信号权重（来源 doc 12/25，0.7）。
- **[中] A 股破位止损前置**：T+1 使破位后当日无法卖出，止损位必须在买入前设定；6% 熔断在跌停无法卖出时失效，需与涨跌停/流动性状态联动判断（来源 doc 25/27，0.7/0.4）。
- **[中] 止损快止盈慢、做错敢割肉**：强化止损触发逻辑与认错检查项（来源 doc 05，0.45）。
- **[低] 回撤干预阈值**：doc 02 的 80% 回撤阈值与白泽更低干预阈值冲突，应忽略不采信（来源 doc 02，0.4）。

### 学习进化 learner

- **[高] 五阶段闭环作为 learner 架构蓝本**：感知 → 决策 → 执行 → 复盘 → 更新；与白泽 DataWorker → analysis → positioning/risk → learner → calibrate 对齐（来源 doc 13，0.6）。
- **[高] 错误类型标签体系**：`chased_move / ignored_news_conflict / stop_too_tight / stop_too_wide / overleveraged / held_too_long` 作为复盘反馈分类，让复盘从空话升级为可统计的错误库（来源 doc 13，0.6）。
- **[高] 复盘触发条件**：仅当一笔完整交易（开仓→平仓）结束才生成教训；教训必须具体结论，禁止"操作失误/行情不好"空话（来源 doc 13，0.6）。
- **[中] 复盘→更新的机制**：定期汇总复盘 + 胜率盈亏统计生成新规则/参数建议，每个参数 clamp 到人工边界；新增影子/A-B/样本外验证后再生效（来源 doc 13，0.6）。
- **[中] 运气与幸存者偏差校准**：高收益样本可能含运气成分，confidence 校准（calibrate）时用可证伪条件约束（来源 doc 24，0.75）。
- **[中] Market Dashboard 每周三查**：公司基本面 / 市场在奖励什么 / 策略是否有效——与质量审查 + learner 阶段结合（来源 doc 29，0.55）。
- **[低] 因子入池门槛**：候选因子须有独立长周期回测证据才入池，无证据标记 [UNSOURCED]（来源 doc 24，0.75）。

### 数据护栏 / 信息环境

- **[高] 信息有效性（price in）检查**：对已在社交媒体/自媒体刷屏的利好降低新增 Alpha 权重；归因时先问"该信息是否已被市场定价"（来源 doc 30，0.5）。
- **[高] 一手信息优先强化**：以巨潮公告/交易所/订单/龙虎榜/北向为准，过滤自媒体转述——与现有 T0>T1>T2 tier 分级一致（来源 doc 30，0.5）。
- **[高] 三层归因分层**：归因/诊断内置"执行 / 配置 / 逻辑"三层判断，避免把买法问题升级成公司逻辑问题（来源 doc 29，0.55）。
- **[中] 失效 Alpha 三信号 → Alpha Lens 预期差识别**：市场误读逻辑（主叙事与基本面差距）/ 夸大风险（恐慌套利场景）/ 未定价机会（新主线早期）（来源 doc 30，0.5）。
- **[中] 情绪反向纪律**：无人问津时研究、人声鼎沸时卖——作为情绪极值时的逆向检查项，须与趋势/基本面共振（来源 doc 30，0.5）。
- **[中] 双信号源"不冲突"才开仓**：信息面冲突即禁止开仓，作为交叉验证 ≥2 独立来源的硬规则延伸（来源 doc 13，0.6）。
- **[中] 跨市场传导时间差信号**：上游现货价格异动（华强北被动元件/存储涨价）→ 海外龙头 → A 股对标，滞后 2-4 周窗口，可作 sector-research/supply_chain 领先信号源；标注 [SPECULATION]（来源 doc 04，0.3）。
- **[低] 结构性快照 + 布尔特征**：factor/diagnosis 特征工程采用语义化布尔字段（如 `macd_hist_rising`），提高下游稳定性（来源 doc 13，0.6）。
