## 一、关键信息提取

### 核心观点
1. 股市本质是为企业融资、为投资者提供投资机会的资本市场，其基本功能是融资与资源配置，**"不是让散户致富"**；短期交易是零和博弈，长期持有指数才是正和博弈（赚经济增长与企业经营红利）。
2. 市场里赚大钱的是机构、大资金、有系统/有信息优势的少数人；散户没有信息、资金、制度优势，**唯一优势是时间与耐心**，只能靠建立自己的交易系统并"知行合一"，不能靠预测对抗市场。
3. 分析股票用三维度框架：宏观（经济周期，股市是经济"晴雨表"）→ 行业（生命周期：初创/成长/成熟/衰退）→ 公司（质地：靠什么赚钱、商业模式、护城河、估值），"**选股先选行业**"。
4. 炒股盈利四模块体系：**选股体系**（有原则有边界、只做能力圈内的）、**交易体系**（有纪律不随意，交易不是预测而是应对与跟随）、**仓位体系**（有分配不赌，单票设上限）、**风控体系**（有底线不硬扛，活下来第一位、赚钱第二位）。
5. 盈利核心是**顺势而为**（趋势一旦形成不会轻易改变）叠加"仓位管理 > 选股能力、止损纪律 > 预测分析、逻辑验证 > 内幕消息、等待 > 操作"四大法则。

### 方法论 / 操作要点
- 三维度分析框架：先判宏观周期 → 再选行业生命周期阶段 → 后评公司质地；"看到股票先问属于哪个行业、什么周期、质地如何，而不是先问能不能买"。
- 四模块交易体系（见核心观点 4）：选股有边界、交易有纪律、仓位有分配、风控有底线。
- 顺势而为两要素：均线系统（多头/空头排列）确认趋势；趋势线"**三次变化规律**"——趋势线变三次行情基本结束（一次缓慢、二次加速、三次见顶）。
- 炒股盈利三原则：保障资本 → 稳健盈利 → 追求卓越。
- 春夏秋冬仓位节奏：春（小范围上涨、温和放量、普遍忽视→观察）；夏（全面普涨、量能放大、媒体关注→重仓介入）；秋（疯狂补涨、天量、全民鼓吹→逐步减仓）；冬（炸板增多、量能萎缩、负面报道→空仓休息）。
- 四大法则：
  1. **仓位管理 > 选股能力**：首次开仓永不满仓，永远留预备队（334 法）。
  2. **止损纪律 > 预测分析**：止损要快、止盈要慢，做错敢于割肉认错（"你分析得再对，市场不按你分析的走也是白扯"）。
  3. **逻辑验证 > 内幕消息**：买入三问——为什么涨（逻辑）、谁在买（资金）、还能涨吗（空间）。
  4. **等待 > 操作**：看不懂就看戏，等待是一种美德；"股市不关门、机会天天有、钱是赚不完的但可以亏完"。
- 游击战策略（散户 vs 机构）：机构劣势=排名压力、持仓压力、船大难掉头；散户优势=时间自由、资金自由、无业绩考核，应"打一枪赚到钱就跑"，用游击战对机构的正规战。
- 选股条件（主力信号）：主力入场迹象 + 成交量放大 + 开始洗盘 + 处于活跃板块 + 强势启动 + **止损放启动点**。
- 买卖点：突破压力位后的"尝试性买点 → 标准买点 → 加速买点"，配合建仓-洗盘节奏；可研究波浪理论（一浪二浪三浪四浪五浪 + ABC 调整浪）。
