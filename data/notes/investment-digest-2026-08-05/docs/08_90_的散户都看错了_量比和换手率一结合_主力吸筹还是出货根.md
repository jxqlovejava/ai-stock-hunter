# 90%的散户都看错了！量比和换手率一结合，主力吸筹还是出货根本藏不住 🚀

## 一、关键信息提取
### 核心观点
- 量比与换手率单独看都会踩坑：量比看"有没有新资金进场"，换手率看"资金是否真刀真枪成交"，两者结合才能判断主力意图。
- 提供"量比 → 换手率 → 交叉验证"三层筛选法，识别主力吸筹 / 出货。
### 关键数据与事实
- 筛法一（量比）：每天 9:35 左右打开量比排行；量比 <3 忽略；重点看量比 >5；数千只股票筛剩一两百只。
- 筛法二（换手率）：换手率 <3% 删除（多为挂单好看/试盘）；关注 3%-8%（资金持续流入、活跃但未失控）；>8% 只入观察名单（机会与风险同步放大）；筛后剩二三十只。
- 交叉验证 4 情形：
  ① 换手率 >5% + 量比 2-3 → 启动信号，走势或加速；
  ② 换手率 5%-10% + 量比 3-5 → 资金持续加仓，主升浪可能形成；
  ③ 换手率 >10% + 量比 >5 → 看位置：低位 = 吸筹，高位 = 警惕出货；
  ④ 换手率 >5% + 量比 <2 → 无新增资金进场，行情尾声或资金撤离，宁可错过不硬扛。
- 口诀：量比看方向，换手看力度。
### 方法论 / 操作要点
- 三层漏斗筛选：①量比 >5 圈定活跃个股 → ②换手率 3%-8% 二次过滤 → ③量比/换手率组合定"启动/加仓/吸筹/出货"信号。
- 位置判定：同一量比换手组合在高位 / 低位意义相反。
- 回避规则：换手率 >5% 但量比 <2 的组合直接回避。
### 文章结论
- 量比 + 换手率交叉验证能提前看出"突然拉升 / 莫名下跌"的主力痕迹，据此识别吸筹与出货。
